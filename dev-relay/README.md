## About Deva

The Agentic AI Instruction Framework provides reusable agents, skills, and instructions that teams and individuals can extend without changing the base framework. We call it Dev Assistant, or **Deva** — it orchestrates the development workflow from Jira analysis through implementation, review delivery, integration, final documentation, and archival. Deva is VS Code-first and uses Copilot Nested Agents; the installer also generates a Claude Code mirror.
